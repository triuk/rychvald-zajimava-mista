# Obrazové materiály

Tento adresář obsahuje fotografie, mapy a výřezy převzaté pro články projektu. Vyčleněním obrázku se nemění původní
dokument v `sources/`.

## Pravidla

- U každého souboru eviduj popis, autora, datum nebo období, původní `source_id`, přesný lokátor, držitele práv a licenci.
- Pokud licenci nebo držitele práv nelze ověřit, uveď přesné označení **„neznámá práva“**.
- Materiál označený „neznámá práva“ lze v projektu zobrazit s úplným původem, ale nesmí být prezentován jako volně
  publikovatelný nebo volně použitelný mimo projekt.
- U mapového portálu lze místo nečitelného nebo technicky nespolehlivého výřezu uvést přímý odkaz na konkrétní mapové
  zobrazení.
