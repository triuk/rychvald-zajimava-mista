# Registr nejistot

Autoritativní vstup je `index.yml`. Jednotlivé úplné záznamy jsou rozděleny do souborů `open-*.yml` a `closed-*.yml`.

Původní soubor `../uncertainties.yml` je zachován jako historický snapshot před potvrzením pravidla z 21. července 2026. Pro aktuální počty a stavy se nepoužívá.

Pravidlo: pokud `Thumbs.db` obsahuje náhled a odpovídající samostatný plný soubor v repozitáři není, plný originál je evidován jako chybějící. Náhled není náhradou originálu.
